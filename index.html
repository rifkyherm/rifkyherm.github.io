Selected Projects

The World Simulation CL

C++CUDAVulkanPython

A 4-billion-year Earth simulation — from dead planet to the present day — with life evolving freely from a single initial replicator. Metabolism is not hardcoded: it is computed from local Gibbs free energy. Core milestones reached — the 4 Ga backbone runs in 31 minutes (21,773 steps), mass conservation < 1×10⁻¹⁴, and the Great Oxidation Event (GOE) emerges as a consequence, not an input.

Deleter v7.0.0 “Omni”

GoFlutterPythonSecurity

A polyglot security platform in one package: bug hunter, high-level debugger, and offline AI assistant — as a desktop app (Flutter, native rendering, no HTML) and a CLI. 64 security checks with 86.1% OWASP Top 10 coverage; multi-language stack-trace parser with automatic root-cause detection; realtime log viewer; lite antivirus with entropy analysis. The AI assistant runs 100% offline — deterministic and auditable.

Herkan Agent

PythonLLM agentsRuntime

An autonomous agent runtime built around one property popular architectures lack: every action touching the outside world passes through a single authorization gate that nobody can bypass — including the agent itself through delegation. Supports 7 LLM providers, depth-limited subagent delegation, a persistent cron scheduler, a token-gated localhost HTTP gateway, context compression, and a budgeted autonomous mode. Verified live against a local LLM (Ollama).

Physarum-Atlas

PythonNumPyAlgorithms

Two slime-mold (Physarum) models built from scratch with NumPy — no scipy/matplotlib — then benchmarked against classical graph algorithms on real city maps. Every tool is hand-written: Delaunay triangulation (Bowyer–Watson), convex hull, MST (Kruskal + union-find), Steiner heuristic, Dijkstra, and a Conjugate Gradient solver. Measured result: the agent network reaches 89–100% coverage on the tested maps.

Lenia-Ω

PythonCUDACellular automata

An extended Lenia — multi-channel, multi-kernel, anisotropic kernels, mass-conservation mode — written as a reference oracle: slow but provably correct, including proof that Game of Life is a special case. Large-scale species search with MAP-Elites for quality-diversity, plus a video renderer.

Komik-Manhwa

PythonSDXLLoRAComfyUI

A manhwa-style comic generation pipeline (vertical Webtoon format) with SDXL: visual-style research, LoRA fine-tuning and conversion, panel-by-panel ComfyUI workflow, and chapter assembly — keeping character consistency across panels via seeds and canonical descriptions.
